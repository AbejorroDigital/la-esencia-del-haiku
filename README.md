# 🌸 La Esencia del Haiku: Más allá de la métrica
### Aplicación de Aprendizaje Autónomo y Poética Japonesa Contemplativa

> **Diseño Curricular y Cátedra:** Profesor Carlos García Torín  
> **Enfoque Pedagógico:** Aprendizaje Autónomo, Teoría Literaria y Prácticas Contemplativas Zen (*Haiku-Dō*)

---

## 🍃 Propósito del Proyecto

**La Esencia del Haiku: Más allá de la métrica** es una aplicación web interactiva de aprendizaje autónomo concebida para desmitificar la simplificación occidental que reduce el haiku a una fórmula matemática de 3 versos y 17 sílabas (5-7-5).

En la tradición clásica japonesa, el haiku no es un acertijo métrico ni un ejercicio de ingenio retórico; es una **vía de despertar espiritual (*Dō*)**, una disciplina de la mirada nacida del silencio, el despojo del ego literario (*Mushin*) y la captación del instante eterno (*Satori*). 

Esta plataforma guía al estudiante en un recorrido en 5 etapas para desaprender el artificio lírico y reaprender a contemplar la realidad cotidiana con ojos limpios de vanidad.

---

## ✨ Características Principales

### 1. 📚 5 Módulos de Estudio Profundo y Accesible
La aplicación organiza el conocimiento en 5 unidades temáticas progresivas con fundamentos teóricos, estética comparada, glosario de términos japoneses y listas de chequeo:
* **Módulo 1: La trampa de la estructura y el abandono del intelecto**
  * Desmontaje del mito del 5-7-5 occidental (*Onji* vs. sílaba).
  * Distinción ontológica entre Haiku y Senryū (la reverencia natural frente a la comedia humana).
  * Cultivo de la mente vacía (*Mushin*) y la imagen sin metáforas.
* **Módulo 2: El Satori: La revelación y el chispazo del instante**
  * El haiku como sismógrafo de la iluminación cotidiana.
  * La tensión polar del *Fueki Ryūkō* (lo inmutable y lo mudable).
  * La cesura o corte sagrado (*Kireji*).
* **Módulo 3: El alma del Haiku: Mono no Aware y Sabi**
  * La suave tristeza ante la impermanencia (*Mono no Aware*).
  * La belleza de la pátina del tiempo y la soledad serena (*Sabi*).
  * El silencio fértil (*Ma*) y la evocación del misterio (*Yūgen*).
* **Módulo 4: El Kigo y la adaptación a Occidente**
  * La palabra de estación (*Kigo*) como respiración cósmica.
  * Descolonización del cliché: cómo escribir desde el ecosistema, clima y flora local occidental.
* **Módulo 5: Los grandes Haijin y el Jisei**
  * La mirada de los cuatro grandes maestros: Matsuo Bashō, Yosa Buson, Kobayashi Issa y Masaoka Shiki (*Ichigo Ichie*).
  * El poema de despedida de la vida (*Jisei*) y la disolución de la frontera entre vivir y morir (*Shōji*).

---

### 2. 🧘 Taller Contemplativo y Auditor de Ego (Mushin Studio)
Un entorno de escritura diseñado para la práctica silenciosa:
* **Cuenco Zen de Atención Plena:** Sonido de cuenco tibetano generado mediante sintetizador Web Audio API para iniciar momentos de silencio interior.
* **Temporizador de Contemplación:** Sesiones guiadas de 5, 10 y 15 minutos para la observación del entorno antes de escribir.
* **Auditor de Artificios en Tiempo Real:** Escáner inteligente que analiza los versos e identifica vestigios del ego lírico (*yo, mi, siento*), metáforas/símiles occidentales (*como, parece*) y adjetivos de juicio emocional (*bello, triste, hermoso*).
* **Contador Aproximado de Sílabas:** Referencia métrica orientativa sin caer en la obsesión numéricas.

---

### 3. 📖 Mi Cuaderno de Campo (Diario del Haijin)
* **Privacidad y Persistencia Local:** Todas las composiciones, observaciones del entorno y reflexiones se guardan de forma privada en el navegador (`localStorage`) sin requerir cuentas de usuario ni servidores externos.
* **Organización por Módulos:** Posibilidad de etiquetar, revisar y filtrar la colección personal según el módulo de estudio.
* **Exportación en Markdown:** Descarga con un solo clic del cuaderno de campo completo en formato `.md` para conservar o imprimir la obra personal.

---

### 4. 🪞 El Espejo del Haijin (Autoevaluación Formativa)
* **Instrumento de Diagnóstico Autónomo:** Permite al estudiante autoevaluar sus versos en las 4 dimensiones clave de cada módulo.
* **Cálculo de Índice de Afinidad Poética:** Puntuación ponderada que determina el nivel (*Nivel Destacado*, *Nivel Competente*, *En Desarrollo*).
* **Consejos Pedagógicos:** Retroalimentación personalizada basada en las enseñanzas del Profesor Carlos García Torín y los maestros clásicos.
* **Registro de Progreso:** Marcado de módulos completados para seguir el avance en el sendero de las 5 estaciones.

---

### 5. 🔍 Comparador Diferencial
* Interfaz interactiva para poner a prueba la intuición del estudiante contrastando ejemplos reales de:
  1. **Haiku Zen Clásico:** La naturaleza hablándose a sí misma.
  2. **Senryū Satírico:** Humor, ironía y anécdota social humana.
  3. **Pseudo-Haiku Occidental:** Exceso de metáfora, intelecto y juicio del autor.

## 🛠️ Tecnologías Utilizadas

* **Framework:** React 18 con TypeScript
* **Empaquetador:** Vite
* **Estilos:** Tailwind CSS v4 (diseño responsivo, tipografía clásica y paleta editorial inspirada en el papel *Washi*)
* **Iconografía:** Lucide React
* **Audio:** Web Audio API (síntesis armónica de cuenco de bronce)
* **Almacenamiento:** LocalStorage API (100% privado y offline)

## 🚀 Uso y Ejecución Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/la-esencia-del-haiku.git
   cd la-esencia-del-haiku
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. Abrir la dirección indicada en el navegador (por defecto `http://localhost:3000`).
